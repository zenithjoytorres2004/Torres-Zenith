# Cloud Provider Comparison

| Infrastructure Component | AWS | Microsoft Azure | Google Cloud |
|---|---|---|---|
| Compute | Amazon EC2 | Azure Virtual Machines | Compute Engine |
| Storage | Amazon S3 | Azure Storage | Cloud Storage |
| Networking | Amazon VPC | Azure Virtual Network | VPC |
| Identity and Access Management (IAM) | AWS IAM | Azure RBAC / Microsoft Entra ID | Cloud IAM |


## 1. Which provider offers the broadest range of services?

AWS offers a very broad range of cloud services covering computing, storage, networking, databases, security, and many other areas. It is a strong choice for organizations that need many different cloud services.

## 2. Which would you recommend for an organization primarily using Microsoft products?

Microsoft Azure would be a good choice for an organization that mainly uses Microsoft products. Azure works closely with Microsoft technologies and uses Microsoft Entra ID and Azure RBAC for identity and access management.

## 3. Which is widely recognized for AI, ML, and Kubernetes?

Google Cloud is widely recognized for its strengths in artificial intelligence, machine learning, and Kubernetes. Google created Kubernetes, and Google Cloud provides services for running Kubernetes workloads.

## 4. What similarities did you observe?

All three providers offer compute, storage, networking, and identity and access management services. They also allow organizations to create scalable cloud infrastructure without having to manage all physical hardware themselves.
