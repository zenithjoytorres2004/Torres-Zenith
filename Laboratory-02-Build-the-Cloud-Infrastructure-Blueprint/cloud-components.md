# Cloud Infrastructure Components

## 1. Compute Resources

### Example
CPU Cores: 2

### Purpose
Compute resources provide the processing power needed to run applications, commands, and services.

### Importance in Cloud Computing
Compute resources are important because cloud applications need processing power to perform tasks and respond to users.

### KillerCoda Environment
The KillerCoda environment provides 1 CPU core. I used the `nproc` command to check the number of available CPU cores.

## 2. Storage Resources

### Example
Disk Capacity: 20 G

### Purpose
Storage resources are used to store the operating system, applications, files, and other data.

### Importance in Cloud Computing
Storage is important because cloud servers need space to save applications, files, and data.

### KillerCoda Environment
My KillerCoda environment has a main disk capacity of 19 G. I found this information using the `df -h` command.

## 3. Networking Resources

### Example
IP Addresses: 172.30.1.2 and 172.17.0.1

### Purpose
Networking allows computers and cloud resources to communicate with each other and with users.

### Importance in Cloud Computing
Networking is important because cloud services need communication between users, servers, applications, and other resources.

### KillerCoda Environment
My KillerCoda environment has IP addresses 172.30.1.2 and 172.17.0.1. I found these addresses using the `hostname -I` command.

## 4. Operating System

### Example
Operating System: Ubuntu 24.04.4 LTS

### Purpose
An operating system manages the computer's hardware and provides a platform for applications and commands to run.

### Importance in Cloud Computing
The operating system is important because cloud servers need an environment to manage resources and run applications and services.

### KillerCoda Environment
My KillerCoda environment is running Ubuntu 24.04.4 LTS. I used the `cat /etc/os-release` command to identify the operating system.
