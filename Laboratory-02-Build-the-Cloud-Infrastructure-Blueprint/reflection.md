# Mission Reflection

## 1. Most Important Cloud Infrastructure Component

I think compute resources are one of the most important cloud infrastructure components because they allow applications and services to run. Without computing power, other resources such as storage and networking cannot be used effectively to provide cloud services.

## 2. Linux and Cloud Computing

Linux supports cloud computing because it provides a reliable operating system for servers and cloud environments. During this activity, I used Linux commands to check information such as the operating system, kernel version, CPU, memory, storage, hostname, and network information.

## 3. Importance of Technical Documentation

Technical documentation is important before deployment because it helps organize information about the infrastructure. It also makes it easier to understand the system, identify resources, troubleshoot problems, and maintain the environment in the future.

## 4. New Skills Learned

I learned how to use basic Linux commands to inspect a server environment. I also learned how to identify compute, storage, networking, and operating system resources. In addition, I learned how to compare cloud providers and create a simple cloud infrastructure diagram.

## 5. GitHub Portfolio Improvement

This laboratory improved my GitHub portfolio by adding a complete cloud infrastructure project. I documented my Linux environment, compared AWS, Microsoft Azure, and Google Cloud, created a cloud architecture diagram, and wrote a reflection about what I learned. This gives me a better understanding of how cloud infrastructure can be documented and organized.
