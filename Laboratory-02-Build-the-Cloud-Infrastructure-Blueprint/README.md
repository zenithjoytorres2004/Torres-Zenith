# Laboratory 02 – Build the Cloud Infrastructure Blueprint

## Mission Overview

In this laboratory, I worked with a Linux environment to learn more about the basic parts of cloud infrastructure. I checked the server's resources, researched different cloud providers, and organized my findings in GitHub. I also made a simple diagram to show how the different cloud components can work together.

## Objectives

- Find and understand the resources available on the Linux server.
- Learn what compute, storage, networking, and operating system resources are used for.
- Compare AWS, Microsoft Azure, and Google Cloud.
- Create a basic cloud infrastructure diagram.
- Practice documenting and organizing my work on GitHub.

## Cloud Infrastructure Components

### Compute Resources

The server uses CPU resources to run programs and processes. I checked the CPU information and number of available cores using Linux commands.

### Storage Resources

Storage is used to keep system files, programs, and other data. I checked the available disk space on the Linux environment to see how much storage was provided.

### Networking Resources

Networking allows the server to communicate with other computers and services. I checked the hostname and IP information to understand how the Linux environment is connected.

### Operating System

The operating system manages the computer's resources and provides the environment for running programs. The environment used in this laboratory was Ubuntu Linux.
