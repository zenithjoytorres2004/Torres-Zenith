# Docker Deployment and Lifecycle 
 
1. docker ps  
Displays the list of containers that are currently running. 
 
2. docker stop 68a764f5b850 <br>
Terminates a running container. 
 
3. docker ps -a  
Lists all containers, including those that have already stopped. 
 
4. docker rm 68a764f5b850 <br>
Removes a container completely from the system.
