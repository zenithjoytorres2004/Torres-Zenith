# Laboratory 04 - Cloud Native Engineer

## Mission Overview
This task is about working with Docker to run and control applications inside containers.

## Objectives
- Learn the difference between VMs and Containers
- Practice basic Docker commands
- Run an Nginx container
- Handle container operations

## Docker Commands Executed
- docker --version
- docker info
- docker pull nginx
- docker run -d -p 8080:80 nginx
- curl http://localhost:8080
- docker ps
- docker stop 68a764f5b850 <br>
- docker rm 68a764f5b850 <br>
