# Reflection

For me, the docker containers perform faster than virtual machines since they don’t require a 
separate full operating system to run. Virtual machines need more time to start 
because they load an entire OS, while containers launch quickly by using the host system.

Port mapping like -p 8080:80 makes it possible to access the container from the host device. 
Without this setup, the service running inside the container would not be available externally.

Using docker rm removes the container along with any stored data inside it. 
This shows that containers are not permanent unless persistent storage is configured.

Containerization improves collaboration between developers and IT teams by providing a 
consistent environment, ensuring applications behave the same across different systems.
