# Laboratory 05 - Cloud Data Engineer

## Mission Overview

This laboratory activity focused on deploying an Object Storage environment using MinIO. The goal was to create a proof-of-concept storage system for a photo-sharing application that needs to store millions of user-uploaded images.

## Objectives

- Understand the three primary types of cloud storage.
- Compare Block Storage, File Storage, and Object Storage.
- Deploy MinIO using Docker.
- Access the MinIO Web Console.
- Create an object storage bucket.
- Upload a test file to the bucket.
- Document the deployment process.

## Tools Used

- GitHub
- KillerCoda Ubuntu Playground
- Docker
- MinIO
- Linux Command Line
- Web Browser

## Skills Learned

- Creating and organizing Markdown documentation.
- Using Linux commands.
- Deploying applications using Docker.
- Working with Object Storage.
- Creating and managing MinIO buckets.
- Uploading objects to cloud storage.
- Documenting cloud infrastructure deployments.
