# Client Recommendations

## Client A – Startup
**Recommended:** AWS  
AWS is cost-effective and scalable for startups.  
Services: EC2, S3, Lambda  

## Client B – University
**Recommended:** Azure  
Azure integrates with Microsoft systems.  
Services: Azure VM, Azure AD, Blob Storage  

## Client C – AI Company
**Recommended:** GCP  
GCP is strong in AI and ML.  
Services: Compute Engine, BigQuery, AI Platform  

## Client D – E-Commerce
**Recommended:** AWS  
AWS supports global scaling and availability.  
Services: EC2, Auto Scaling, CloudFront  

---

## Decision Matrix

| Requirement | Platform | Reason |
|------------|---------|--------|
| Startup | AWS | Low cost |
| Enterprise | AWS | Flexible |
| Microsoft | Azure | Integration |
| AI/ML | GCP | Advanced tools |
| Kubernetes | GCP | Native support |
| Global App | AWS | Global infra |
