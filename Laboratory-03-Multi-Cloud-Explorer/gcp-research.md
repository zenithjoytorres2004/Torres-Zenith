# Google Cloud Platform (GCP)

The Google Cloud Platform (GCP) is Google’s suite of cloud services (launched in 2008) known for high-performance computing, advanced data analytics, and artificial intelligence.

## Key Features

- **Global Infrastructure:** Runs on Google's global fiber network organized into **Regions** and **Zones**.
- **Google Cloud Console:** A central web dashboard used to deploy, manage, and monitor all cloud resources.

## Core Services

| Service | What It Does |
| :--- | :--- |
| **Compute Engine** | Scalable virtual machines |
| **Cloud Storage** | Secure object and file storage |
| **BigQuery** | Serverless, high-speed data warehouse |
| **VPC (Virtual Private Cloud)** | Private, isolated global networks |

## Advantages & Use Cases

- **Benefits:** Industry-leading AI/ML features, powerful big data capabilities, native Kubernetes container support, and fast network speeds.
- **Common Uses:** Building AI applications, running large-scale analytics, and hosting web applications.
