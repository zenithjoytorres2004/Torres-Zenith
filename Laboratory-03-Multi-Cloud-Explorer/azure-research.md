# Microsoft Azure

Microsoft Azure is Microsoft’s cloud platform (launched in 2010) that provides computing, storage, networking, and analytics online without needing physical hardware.

## Key Features

- **Global Infrastructure:** Uses **Regions** and **Availability Zones** worldwide for high speed and uptime.
- **Azure Portal:** A single web dashboard to manage and monitor all your cloud resources.

## Core Services

| Service | What It Does |
| :--- | :--- |
| **Virtual Machines (VMs)** | Virtual servers |
| **Blob Storage** | Unstructured data & file storage |
| **Azure SQL Database** | Managed relational database |
| **Virtual Network (VNet)** | Private, isolated networks |

## Advantages & Use Cases

- **Benefits:** Seamless Microsoft integration (Active Directory, Windows Server), strong hybrid cloud support, and enterprise-grade security.
- **Common Uses:** Migrating Microsoft systems, running enterprise software, and cloud backup/disaster recovery.
